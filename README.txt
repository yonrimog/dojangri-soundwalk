양도면 사운드워크 현장 테스트 버전

이번 버전은 확인된 1번 출발 지점만 GPS 테스트하도록 만들었습니다.
- 1번 출발: 위도 37.653333, 경도 126.445000, 반경 15m
- 2~8번: 좌표 미등록 및 비활성화 (잘못된 좌표로 재생되지 않도록 처리)
- 그림 지도와 기존 음원 6개는 유지

테스트 방법
1. 이 폴더 전체를 기존 GitHub Pages 사이트 저장소에 업로드/교체합니다.
2. HTTPS로 공개된 사이트 주소를 휴대전화에서 엽니다.
3. GPS 테스트 시작을 누르고 위치 권한을 허용합니다.
4. 출발 지점에 가까워지면 화면의 출발 표시가 파란색으로 깜빡이고 1번 음원이 재생됩니다.
5. 화면의 GPS 거리와 정확도도 확인할 수 있습니다.

중요
- admin.html에서 다시 좌표를 수정한 경우, 설정 파일(config.json)을 다시 내려받아 이 폴더의 config.json과 교체해야 합니다.
- 현재 파란 점은 출발 지점에 도착했을 때 표시하는 도착 표시입니다. GPS 점이 그림 지도 위에서 이동하는 기능은 지도 전체의 좌표 보정이 필요하므로 아직 포함하지 않았습니다.
- 브라우저의 file:// 로컬 파일로는 GPS/설정 fetch가 정상 동작하지 않습니다. 반드시 HTTPS 사이트에서 테스트하세요.
